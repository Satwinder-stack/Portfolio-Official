PURPOSE

This project provides a comprehensive, web-based vehicle rental management system. Developed as a collaborative effort, the platform provides users with real-time tracking of vehicle availability, strict user verification mechanisms, and an integrated digital wallet simulation to handle financial transactions securely. Additionally, it implements automated business logic, including a 24-hour maintenance buffer, to ensure fleet availability and system reliability.

CORE FEATURES

  • Real-time vehicle availability tracking and dynamic filtering.
  • Secure digital wallet simulation for user transactions.
  • 24-hour buffer logic for routine vehicle maintenance.
  • Role-based administrative dashboard for verification and bookings.
